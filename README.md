# MyERP - Система управления торговым предприятием

Легковесная ERP-система для автоматизации учета поставок, продаж и товародвижения. Разработана на платформе WPF (C# + XAML) с использованием базы данных MySQL.

## 🚀 Основные возможности

*   **Справочники**: Управление товарами, категориями, единицами измерения, складами, поставщиками и покупателями.
*   **Документооборот**: Создание и редактирование заказов поставщикам, поставок и продаж.
*   **Бизнес-логика**: 
    *   Разделение документов на «Черновики» и «Проведенные».
    *   Автоматическая блокировка интерфейса при проведении документа (запрет редактирования).
    *   Автоматический расчет остатков товаров на складах на основе проведенных поставок и продаж.
*   **Роли и доступ**: Разграничение прав (Администратор, Бухгалтер). Скрытие определенных разделов для роли «Бухгалтер».
*   **Удобный интерфейс**: Современный UI с карточками, тенями, динамическими вкладками и цветовым кодированием кнопок. Поиск и фильтрация по всем таблицам.

## 🛠 Технологический стек

*   **Язык**: C# (.NET 6 / .NET 7 / .NET 8)
*   **UI**: WPF (Windows Presentation Foundation)
*   **База данных**: MySQL / MariaDB
*   **Библиотека подключения**: MySqlConnector
